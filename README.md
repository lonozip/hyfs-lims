# 核与辐射安全技术 LIMS 系统

核与辐射安全技术实验室信息管理系统（LIMS）是基于 Django 框架开发的专业实验室管理平台，用于管理实验室的客户、订单、方案、样品和报告等业务流程。

## 功能特性

### 核心功能模块

1. **客户管理**
   - 客户信息的增删改查
   - 客户搜索与筛选
   - 支持批量导入客户数据（自动去重）

2. **订单管理**
   - 订单创建与编辑
   - 订单状态跟踪
   - 关联客户信息

3. **方案管理**
   - 方案创建与编辑
   - 客户与订单联动选择（支持搜索）
   - 样品类型多选与描述选择
   - 样品描述数量设置
   - 标准关联管理
   - 员工分配管理
   - 方案完成自动生成报告

4. **样品管理**
   - 样品信息自动生成（根据方案配置）
   - 样品状态管理
   - 关联方案和订单信息
   - 样品搜索功能
   - 样品创建自动生成测试记录
   - 按方案分页显示

5. **测试管理**
   - 测试记录管理
   - 样品类型描述关联
   - 地址信息录入
   - 测试照片上传（支持相机照片格式）
   - 测试照片缩略图展示
   - 测试搜索功能
   - **辐射剂量率专用字段**：点位描述、经纬度、高程、仪器示值(Rγ1-5)、宇宙射线、k3、平均值、标准差

6. **报告管理**
   - 报告自动生成（方案完成时）
   - PDF报告导出（美观紧凑格式）
   - 报告审核流程（编制→审核→签发）
   - 测试更新同步报告
   - 地址和照片缩略图展示

7. **标准管理**
   - 测试标准管理
   - 辐射卫生标准管理
   - 标准库管理

8. **组织管理**
   - 部门管理
   - 职位管理
   - 员工信息管理（含员工编号）

9. **员工账号管理**
   - 员工账号创建与管理
   - 系统权限控制（方案管理、样本管理、标准管理、组织架构、样品类型管理、样品类型描述、管理后台）
   - 初始密码统一设置

10. **导入模板管理**
    - 模板文件上传与管理
    - 关联样品类型描述
    - 模板下载功能
    - 支持X、γ辐射剂量率等特殊模板

11. **首页仪表盘**
    - 测试状态分布图表
    - 数据统计概览

## 技术栈

- **框架**: Django 6.0
- **语言**: Python 3.13
- **前端**: Bootstrap 5, Select2, Chart.js
- **数据库**: SQLite（开发环境）/ PostgreSQL（生产环境）
- **PDF生成**: weasyprint

## 快速开始

### 环境要求

- Python 3.10+
- pip
- Git

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd senaite.lims/senaite_lims
   ```

2. **创建虚拟环境**
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   ```

3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

4. **数据库迁移**
   ```bash
   python manage.py migrate
   ```

5. **创建超级用户**
   ```bash
   python manage.py createsuperuser
   ```

6. **运行开发服务器**
   ```bash
   python manage.py runserver
   ```

7. **访问系统**
   - 访问 http://127.0.0.1:8000/
   - 使用超级用户账号登录

## 数据导入

系统提供了多种数据导入功能：

### 导入客户数据

将客户数据文件（Markdown格式）放置在 `导入资料/` 目录下，系统支持自动导入并去重。

### Excel批量导入测试数据

系统支持通过Excel模板批量导入测试数据，特别针对X、γ辐射剂量率类型提供专用模板。

#### 导入流程

1. 在测试管理页面点击"下载导入模板"
2. 根据样品类型描述下载对应模板（辐射剂量率类型自动使用专用模板）
3. 填写Excel数据（支持点位描述、经纬度、高程、仪器示值等字段）
4. 上传填写好的Excel文件完成导入

#### 辐射剂量率专用字段

| 字段名 | 说明 | 数据类型 |
|--------|------|----------|
| 序号 | 样本序号（从1开始） | 整数 |
| 点位描述 | 测量点位描述 | 字符串 |
| 经度（E） | 东经坐标 | 数值 |
| 纬度（N） | 北纬坐标 | 数值 |
| 高程（H） | 海拔高度 | 数值 |
| 仪器示值Rγ(1-5) | 5次仪器测量值 | 数值 |
| 宇宙射线 | 宇宙射线值 | 数值 |
| k3 | k3系数 | 数值 |
| 平均值 | 计算平均值 | 数值 |
| 标准差 | 计算标准差 | 数值 |
| 备注 | 备注信息 | 字符串 |

### 导入模板管理

系统支持管理不同样品类型描述的导入模板：

1. 在侧边栏点击"导入模板管理"
2. 可创建、编辑、删除模板
3. 关联样品类型描述，实现自动匹配
4. 支持模板文件下载

## 使用说明

### 添加方案流程

1. 登录系统后，点击"方案管理"
2. 点击"添加方案"按钮
3. 填写方案基本信息（名称、描述等）
4. 选择客户（支持搜索）
5. 根据客户选择关联的订单（支持搜索）
6. 选择样品类型（支持多选）
7. 为每个样品类型选择描述并设置数量
8. 选择关联标准
9. 分配负责员工
10. 点击"保存"完成创建（自动生成样品和测试记录）

### 测试管理流程

1. 在"测试管理"页面查看所有测试记录
2. 点击测试ID进入详情页
3. 填写测试结果、地址信息
4. 上传测试照片
5. 保存测试记录（自动同步更新报告）

### 生成报告流程

1. 方案创建时自动生成报告草稿
2. 在报告详情页面查看关联样品和测试
3. 提交审核→审核通过→签发报告
4. 可下载PDF版本

## 配置说明

### 数据库配置

在 `senaite_lims/settings.py` 中配置数据库：

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}
```

### 媒体文件配置

```python
MEDIA_ROOT = BASE_DIR / 'media'
MEDIA_URL = '/media/'
```
